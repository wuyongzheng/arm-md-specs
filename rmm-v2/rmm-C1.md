## Chapter C1

## RMM constants

This section describes constants which are used in the definition of RMM commands or RMM abstract state.

## C1.1 RMM\_NUM\_PERM\_OVERLAY\_INDICES

Number of permission overlay indices.

DRAFT

The value of RMM\_NUM\_PERM\_OVERLAY\_INDICES is 15.

## C1.2 RMM\_RTT\_PAGE\_LEVEL

RTT level of a page entry.

The value of RMM\_RTT\_PAGE\_LEVEL is 3.

## C1.3 RMM\_RTT\_TREE\_PRIMARY

Index of primary RTT tree.

The value of RMM\_RTT\_TREE\_PRIMARY is 0.

## C1.4 RSI\_GRANULE\_SIZE

Size of an RSI Granule in bytes.

The value of RSI\_GRANULE\_SIZE is 0x1000.
